# Level 2 — Intermediate

## Task 3: Advanced CSS and responsive design

**Where to look:** `public/css/style.css`, `views/partials/header.ejs`.

- Bootstrap's responsive grid is combined with custom project/portfolio styling.
- Cards use transitions, status badges, mobile breakpoints, and reduced-motion support.

**Try it:** use browser responsive mode at mobile and desktop widths; check navigation, forms, and project cards.

## Task 4: Complex validation and dynamic DOM manipulation

**Where to look:** `src/lib/validation.js`, `public/js/app.js`, `views/dashboard.ejs`.

- Password strength and project constraints are checked on both client and server.
- Project cards, character counts, errors, and edit/cancel states update dynamically.
- Dashboard sections use hash-based client-side navigation (`#projects`, `#weather`, and `#github`).

**Try it:** add, edit, and delete a project without navigating away. Change tabs and use the browser back button.
